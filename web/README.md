# web

The LAN BUNKER site: Astro 6, server rendered on Cloudflare Workers, Tailwind 4.
The root `README.md` describes the whole repository. This file covers the site.

## Commands, from `web/`

| Command      | Action                                                         |
| ------------ | -------------------------------------------------------------- |
| `pnpm dev`   | Dev server on `localhost:4321`. It talks to the API on `:3000` |
| `pnpm build` | Production build into `dist/`                                  |
| `pnpm check` | `astro check`, the type check                                  |
| `pnpm lint`  | oxlint                                                         |
| `pnpm fmt`   | oxfmt                                                          |
| `pnpm e2e`   | Playwright against a fresh API and the dev site                |

From the repository root, `make web-check` runs format, lint, type check and
build. `make web-e2e` runs the browser tests.

## Structure

```
src/pages/              one file per route, /admin is the backoffice
src/actions/            form handlers: accounts and admin in index.ts, tournaments in tournaments.ts
src/middleware.ts       session cookie to Astro.locals.player, forced password change
src/lib/api.ts          typed client over openapi-fetch
src/lib/api-types.d.ts  generated by `make api-types`, never edited by hand
src/components/ui/      Button, Panel, Kv, Badge, Prompt, Pager, Glyph, Countdown
src/components/*.tsx    React islands: BracketView, LiveBracket, BracketEditor, GlyphMark
src/layouts/            Layout for the site, AdminLayout for the backoffice
src/content/            events and the about page, as Markdown
e2e/                    Playwright tests
```

## Dependencies to know about

`vite` is pinned to the major that Astro ships, both as a dev dependency and as
a pnpm override. The React integration pulls the next major on its own, and two
copies make the Tailwind plugin type-check against the wrong one.

## Environment

`API_URL` names the Rust API. In production it comes from a Worker var. Locally
it comes from the shell or `.env`, with `http://127.0.0.1:3000` as the default.
The schema is in `astro.config.mjs`.
