# web

The LAN BUNKER site: Astro 7, server rendered on Cloudflare Workers, with
Tailwind 4 and a few React islands. The rules for the code are in `CLAUDE.md`.

## Commands

From the repository root:

| Command          | What it does                                                       |
| ---------------- | ------------------------------------------------------------------ |
| `make web-dev`   | Dev server on `localhost:4321`, against the API on `:3000`         |
| `make web-check` | Format, both type checkers, lint, build. Run it before a commit    |
| `make web-e2e`   | Playwright against a fresh API on `:3999` and the production build |

From `web/`: `pnpm dev`, `pnpm build`, `pnpm typecheck`, `pnpm check`,
`pnpm lint`, `pnpm fmt`, `pnpm e2e`, `pnpm optimize:imgs`.

## Structure

```
src/pages/          one file per route. /admin is the backoffice
src/actions/        form handlers: accounts, events, tournaments
src/middleware.ts   session, forced password change, security headers
src/lib/api.ts      the typed API client. Every call goes through call or callEmpty
src/lib/            schemas, session, error messages, dates, shared styles
src/components/     Astro components, React islands (*.tsx), ui/ primitives
src/layouts/        Layout for the site, AdminLayout for the backoffice
e2e/                Playwright tests, helpers in support.ts
```

`src/lib/api-types.d.ts` is generated by `make api-types`. Never edit it.

## Environment

`API_URL` lives in `wrangler.jsonc`. A Worker var wins over the shell in local
mode, so a run picks a wrangler environment:

| Environment | `API_URL`               | Set by     |
| ----------- | ----------------------- | ---------- |
| `dev`       | `http://127.0.0.1:3000` | `pnpm dev` |
| `e2e`       | `http://127.0.0.1:3999` | Playwright |
| top level   | production              | the deploy |

The `e2e` port must match `API_PORT` in `playwright.config.ts`. There is no
default, so a run without a value fails.

## Tooling notes

- **Two formatters, one style.** `oxfmt` formats every file it can parse, and
  `prettier` formats `.astro`. The editor uses the same pair through
  `.vscode/settings.json`.
- **Two type checkers.** `pnpm typecheck` is TypeScript 7, fast, for `.ts` and
  `.tsx`. `pnpm check` is `astro check`, the only checker for `.astro`. It needs
  TypeScript 6, so `typescript` stays on 6.x and the `tsgo` alias holds 7.x.
- **`compressHTML: true`** keeps the whitespace rules of Astro 6. The Astro 7
  default joins two inline elements that only a line break separates.
- **Playwright** serves the build with `astro preview` and sets
  `ASTRO_PREVIEW_BACKGROUND=0`, so the server stays in the foreground.
